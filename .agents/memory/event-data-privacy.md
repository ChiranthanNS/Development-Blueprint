description: Privacy constraint for uploaded institutional event materials in this project.

Keep uploaded files, extracted text, event records, photos, and generated reports temporary in the browser session. Do not add a permanent database, login, or server-side file storage.

**Why:** The user explicitly requested that institutional event information not be permanently stored.

**How to apply:** Preserve in-memory processing and clear project data when a new project starts or the browser session ends.

The attached DOCX and PDF are reference examples only: use the DOCX to understand the expected input structure and the PDF to guide the output design. Do not treat the sample event records as the user's intended published issue.

**Why:** The user clarified that the files were uploaded to demonstrate how input should look and what output should look like.

**How to apply:** Use the examples to guide importer and PDF behavior. Test structure and layout with temporary data, and publish only event content the user supplies for an actual issue.
