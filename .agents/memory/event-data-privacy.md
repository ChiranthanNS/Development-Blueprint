---
name: Session-only event data
description: Privacy constraint for uploaded institutional event materials in this project.
---

Keep uploaded files, extracted text, event records, photos, and generated reports temporary in the browser session. Do not add a permanent database, login, or server-side file storage.

**Why:** The user explicitly requested that institutional event information not be permanently stored.

**How to apply:** Preserve in-memory processing and clear project data when a new project starts or the browser session ends.
